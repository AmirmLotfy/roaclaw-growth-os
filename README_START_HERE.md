- Distinguish **ON_DEVICE**, **IN_CLOUD**, and **UNAVAILABLE** using actual SDK results. Never fake a Nano 4 test or offline behavior.
- Never claim sample data are live advertiser account data. Display a visible `DEMO DATA` label.
- Chrome extension and hosted SaaS constitute **one Web platform**, not multiple eligible platforms.
- Never pretend an OAuth integration, video upload, Devpost submission, ad publish, or browser action succeeded without a verifiable result.
- User specifically requested no AI-slop visuals or copy: no violet/cyan gradients, no glassmorphism dashboard, no robot/brain/sparkles mascots, no meaningless growth rhetoric.
- Only perform real ad-account changes through authorized official APIs, with role permissions, confirmation, and a complete action log.
- Do not commit API secrets, service accounts, tokens, sensitive browsing data, or real client records.
