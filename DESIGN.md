# ROACLAW design

The dashboard uses a navy workspace rail and a cool, light audit surface. The form puts the page, inference mode, and run button together. Results put the observed prices alongside evidence and the proposed Chrome bookmark.

The updated visual system is in [Design language](design/DESIGN_LANGUAGE.md). [Research](design/RESEARCH_OUTPUT.md) records the inspected Mobbin and Refero references. [Tokens](design/tokens.css) define the web palette and typography. The web app and Chrome panel use original layouts. Both show device, cloud, approval, and receipt states only when the relevant integration reports them.
