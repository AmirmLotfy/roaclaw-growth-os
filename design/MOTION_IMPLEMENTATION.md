# Motion implementation

The site has one signature entrance. The storefront photo settles into place, and a thin rule reveals across it. The original artwork remains in the final position and is readable when motion is reduced.

The design’s other motion follows user actions. Switching proof tabs briefly settles the active panel. Buttons give focus, hover, and pressed-state feedback. The dashboard uses a short transition when an operation reports progress or a result. Chrome retains an in-place approval review with state changes, distinctive focus, and restrained hover motion.

The web app and side panel respect `prefers-reduced-motion`. Keyboard navigation and labels are available independently of motion. The scene edit uses verified UI captures and original title frames.
